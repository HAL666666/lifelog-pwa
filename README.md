# ライフログ（PWA）

スマホ向けのローカル完結型ライフログ Web アプリです。写真・メモ・リマインダー・ポモドーロタイマーを、端末内の IndexedDB に保存します。ログイン不要・サーバー不要の静的サイトです。

## 機能（v1）

- **写真**: ギャラリー／カメラから取り込み。EXIF の撮影日時（DateTimeOriginal）で日付に振り分け（なければファイル更新日時）。サムネイル＋縮小画像を保存
- **月カレンダー**: 写真・メモ・リマインダーのある日にマーカー表示。日付タップで詳細
- **メモ**: 日付ごとの短いテキスト（追加・編集・削除）
- **リマインダー**: タイトル＋日時。アプリを開いている間のみ通知（Service Worker `showNotification`）
- **ポモドーロ**: 既定 25/5 分（変更可）。終了時刻を保存するためバックグラウンドやリロード後も正確。Wake Lock オプション
- **データ**: JSON エクスポート／インポート（写真は任意・Base64 のため巨大化に注意）
- **カレンダーの印**: 写真＝青い丸、メモ＝黄色の四角、リマインダー＝赤い三角、習慣達成＝緑のチェック（うすい＝一部）、やること完了＝紫の星。凡例つき、3/6/12か月表示にも小さく表示
- **コラージュ**: 日付を選ぶとその日の写真が全部チェック済みで並び、外したい写真を外して作成（1〜9枚を自動レイアウト、日付スタンプ入り）。アプリ内（IndexedDB `collages`）に保存＋ダウンロード。毎日最初に開いたとき、前日に写真2枚以上かつ未作成なら「昨日のコラージュを作る？」
- **サムネの文字**: 写真・コラージュ・ノート表紙に日付（例：10/19（月））とタイトルを重ねる（設定 > 表示 で切替、既定オン）
- **習慣**: 最近14日（全部達成の日はうすく、未達の日を強調）、ガントの「習慣」タブ（1/3/6か月）、段階バッジ・組み合わせバッジ（計36種）
- **受信箱で取り込める種類**: plan（予定）・todo/reminder/deadline・memo・habit（習慣）
- **データ保護**: 起動時に `navigator.storage.persist()` を要求（設定 > データ保護に状態と使用量）。最終書き出しから14日以上（または未実施）で控えめなバックアップ案内バナー（× で3日間非表示）。追加の localStorage キーは `lastExportAt` と `exportReminderSnoozeUntil` のみ

## GitHub Pages への公開

ビルド不要です。リポジトリのルート（または `/docs`）にこのファイル一式を置き、次の手順で公開できます。

1. GitHub にリポジトリを作成し、この内容を `main` ブランチに push
2. **Settings → Pages**
3. **Source**: Deploy from a branch
4. **Branch**: `main` / **Folder**: `/ (root)`（`/docs` に置いた場合は `/docs`）
5. 保存後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス

パスはすべて相対指定のため、サブパス配下でも動作します。

## ホーム画面に追加

- **iPhone (Safari)**: 共有ボタン →「ホーム画面に追加」
- **Android (Chrome)**: メニュー（⋮）→「アプリをインストール」または「ホーム画面に追加」

## 既知の制限

- **通知**: iPhone ではホーム画面追加済みかつ iOS 16.4 以降が必要。v1 にサーバープッシュはなく、**アプリを開いている（フォアグラウンド）間のみ**リマインダーが発火します。起動時に期限切れも確認します。
- **ポモドーロ通知**: 同様に、可能な場合のみ音・バイブ・通知を出します。
- **容量**: 写真を多く保存すると端末ストレージを消費します。エクスポートに写真を含めると JSON が非常に大きくなります。
- **Google カレンダー連携**: v1 では未対応です。

## ローカルでの確認

```bash
cd lifelog-pwa
python3 -m http.server 8080
# ブラウザで http://127.0.0.1:8080/ を開く
```

（`file://` では Service Worker や一部 API が動かないため、必ず HTTP で開いてください。）

## ライセンス

アイコン生成スクリプト・アプリ本体は本リポジトリの利用に合わせて自由に使えます。EXIF パーサは自前実装です。
